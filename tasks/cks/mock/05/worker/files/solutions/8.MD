# Solution

Two problems in `/var/work/8/Dockerfile`. Change only existing lines, do not add or delete lines.

````
vim /var/work/8/Dockerfile
````

1. apt cache is removed in a separate `RUN` (separate image layer), so `/var/lib/apt/lists/*` stays in the previous layer.
   Chain the cleanup to the install `RUN`:

````
.....
RUN set -ex; \
    apt-get update; \
    apt-get install -y --no-install-recommends \
        apt-transport-https \
        ca-certificates \
        dirmngr \
        gnupg; \
    rm -rf /var/lib/apt/lists/*
.....
````

2. The container runs as `root`. Use the dedicated `couchdb` user created at the top of the Dockerfile:

````
.....
USER couchdb
CMD ["/opt/couchdb/bin/couchdb"]
````
