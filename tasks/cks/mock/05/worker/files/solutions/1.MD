> The node has sysdig 0.40.1 installed on purpose: sysdig 0.41.x crashes at startup on containerd nodes.
> The same log can also be produced with `falco`: write a rule with `condition: container.image.repository contains nginx` and output `%evt.time,%container.id,%container.name,%user.name,%k8s.ns.name,%k8s.pod.name`, run `timeout 30 falco -U -r <rule file>`, then strip the `HH:MM:SS.nnnnnnnnn: Warning ` prefix (e.g. `grep -oE '[0-9]{2}:[0-9]{2}:[0-9]{2}\.[0-9]{9},[^ ]+'`).
